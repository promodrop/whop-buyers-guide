# What a Whop sale costs the seller

Buyers don't pay these fees directly, but they explain why some creators price the way they do. Whop lists its seller fees on its official fees page.

Promo Drop keeps a small open dataset of that page: each fee, its percentage, any fixed amount in US dollars, what it is charged on, the condition, the source URL and the date it was checked. New snapshots are added as new dated files, and old ones are never edited, so the table shows how pricing changes over time.

- Dataset (CSV, CC BY 4.0): [github.com/promodrop/whop-fees-dataset](https://github.com/promodrop/whop-fees-dataset)
- Archived copy: [Zenodo, DOI 10.5281/zenodo.23693447](https://doi.org/10.5281/zenodo.23693447)
- Try the numbers: [Whop fee calculator](https://promodrop.codes/tools/whop-fee-calculator)

Source: [Whop fees page](https://docs.whop.com/fees). Snapshot dated 27 October 2026.
